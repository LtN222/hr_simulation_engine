INCREMENTAL SIMULATION FLOW

De generator ondersteunt twee modi:

FULL SIMULATION

Wordt gebruikt om een volledige dataset te genereren.

Pipeline:

run_simulation()
→ initial workforce
→ simulatie van meerdere weken
→ volledige dataset schrijven

INCREMENTAL SIMULATION

Wordt gebruikt voor periodieke updates.

Pipeline:

run_incremental_simulation()

    │
    ▼

load simulation_state

    │
    ▼

start vanaf laatste week

    │
    ▼

simulate_week()

    │
    ▼

nieuwe records toevoegen

    │
    ▼

update simulation_state

SIMULATION STATE

De voortgang van de simulatie wordt opgeslagen in:

simulation_state

Kolommen:

id
current_year
current_week
last_run

Dit bepaalt waar de volgende incremental run moet starten.

CENTRAAL DATA OBJECT

Tijdens de simulatie wordt alle data opgeslagen in:

state

Dit is een dictionary met pandas DataFrames.

Voorbeeld:

state = {

"dim_employee": dataframe,

"fact_employment": dataframe,

"fact_absence": dataframe,

"fact_performance_review": dataframe

}

Elke generator functie:

neemt state als input
wijzigt of voegt data toe
geeft state terug

BELANGRIJKSTE GENERATOR MODULES

population.py
Genereert de initiële workforce.

dimensions.py
Bouwt structure dimensions zoals department en role.

allocation.py
Verdeelt headcount over rollen.

employees.py
Genereert employees en employment records.

simulation.py
Orchestratie van wekelijkse events.

simulation_attrition.py
Simuleert uitstroom van werknemers.

absence_simulation.py
Genereert verzuimhistorie.

performance_simulation.py
Genereert performance reviews.

----------------------------------------------------------------------------------------------

DATABASE PIPELINE

write_to_sql.py verzorgt het schrijven naar Azure SQL.

De pipeline:

DataFrames verzamelen uit state

tabellen in juiste volgorde schrijven

primary keys toepassen

foreign keys toepassen

indexes maken

retention policy uitvoeren
