Gebruikershandleiding
HR Data Generator – Nieuwe sector toevoegen

Deze handleiding beschrijft hoe je met de HR Data Generator een nieuwe dataset kunt genereren voor een andere sector, bijvoorbeeld horeca, retail of zorg.

De generator gebruikt een config-gedreven architectuur. Nieuwe sectoren worden toegevoegd door configuratiebestanden te maken, zonder dat de Python-code aangepast hoeft te worden.

----------------------------------------------------------------------------------------------
OVERZICHT VAN DE PIPELINE

De generator werkt volgens de volgende stappen:

sector config
↓
initial workforce generation
↓
event simulation (per week)
↓
dataframes
↓
write to Azure SQL

De belangrijkste mappen zijn:

config/
sector_config.json
schema_config.json

src/
generator/
database/
simulation/

azure_function/
function_app.py

----------------------------------------------------------------------------------------------

STAP 1 — Sectorconfig maken

Maak een nieuw configuratiebestand in de map:

config/

Bijvoorbeeld:

config/horeca.json

Dit bestand definieert de sector en bevat onder andere:

organisatie structuur

rollen

salarisranges

locaties

attrition gedrag

contractregels

opleidingsverdeling

afwezigheidsgedrag

Zie het bestand maakindustrie.json voor een voorbeeld.

----------------------------------------------------------------------------------------------

STAP 2 — Schema configuratie maken

Maak een schema bestand in:

config/

Bijvoorbeeld:

config/hr_horeca_schema.json

Dit bestand definieert de database structuur:

dimension tables

fact tables

primary keys

foreign keys

datatype mapping

In de meeste gevallen kun je dit bestand eenvoudig kopiëren van een bestaande sector, bijvoorbeeld:

hr_maakindustrie_schema.json

Aanpassen is alleen nodig als de sector specifieke velden nodig heeft.

----------------------------------------------------------------------------------------------

STAP 3 — Database instellen

In de sectorconfig staat de database naam:

"database": "hr_horeca"

De Azure Function gebruikt deze waarde om te bepalen naar welke database geschreven wordt.

De connectie wordt opgebouwd via een template in:

local.settings.json

Voorbeeld:

{
"Values": {
"SQL_CONNECTION_TEMPLATE":
"Driver={ODBC Driver 18 for SQL Server};Server=tcp:server.database.windows.net;Database={database};Uid=user;Pwd=password;Encrypt=yes;"
}
}

De placeholder {database} wordt automatisch vervangen door de waarde uit de sectorconfig.

Let op:

De database moet al bestaan in Azure SQL voordat de generator wordt uitgevoerd.

----------------------------------------------------------------------------------------------

STAP 4 — Sector kiezen

In de Azure Function wordt de sector gekozen.

Dit kan bijvoorbeeld via een parameter:

/api/generate_hr_data?sector=horeca

Als geen sector wordt opgegeven, wordt de standaardsector gebruikt.

----------------------------------------------------------------------------------------------

STAP 5 — Function lokaal starten

Start de Azure Function lokaal met:

func start

De API wordt dan beschikbaar op:

http://localhost:7071/api/generate_hr_data

----------------------------------------------------------------------------------------------

STAP 6 — Dataset genereren

Roep de API aan:

GET /api/generate_hr_data

De pipeline voert dan automatisch uit:

initial workforce generation

HR event simulation

schrijven naar SQL

De volgende tabellen worden gevuld.

DIMENSION TABLES

dim_employee
dim_role
dim_department
dim_location
dim_hire_source
dim_education_level
dim_absence_type
dim_event_type
dim_reden_vertrek

FACT TABLES

fact_employment
fact_employment_attribute
fact_absence
fact_performance_review

----------------------------------------------------------------------------------------------

STAP 7 — Incremental updates

De generator ondersteunt ook incremental simulatie.

De voortgang wordt opgeslagen in de tabel:

simulation_state

Deze bevat:

current_year
current_week
last_run

Bij een incremental run wordt alleen nieuwe data voor de volgende weken gegenereerd.

Dit voorkomt dat de volledige dataset telkens opnieuw gegenereerd wordt.

----------------------------------------------------------------------------------------------

VEELGEMAAKTE FOUTEN

Sectorconfig mist schema

"schema": "hr_horeca_schema"

Database naam ontbreekt

"database": "hr_horeca"

Database bestaat niet

De database moet eerst in Azure SQL worden aangemaakt.

Structure ratios tellen niet op

Controleer dat de fte_ratio waarden logisch verdeeld zijn.

----------------------------------------------------------------------------------------------

SIMULATIEGEDRAG AANPASSEN

Gedrag van de generator kan worden aangepast via de sectorconfig.

Voorbeelden:

attrition
→ uitstroom van werknemers

contract_rules
→ tijdelijk vs vast contract

locations
→ verdeling van werknemers over locaties

education_distribution
→ opleidingsniveau van werknemers

absence
→ verzuimgedrag

----------------------------------------------------------------------------------------------

SAMENVATTING

Een nieuwe sector toevoegen vereist alleen:

1️⃣ sector configuratie maken
2️⃣ schema configuratie maken
3️⃣ database instellen
4️⃣ Azure Function uitvoeren

De generator maakt vervolgens automatisch een complete HR dataset.
