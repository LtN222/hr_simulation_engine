```bash
python -m venv .venv
```

## Usage
For creating a custom dataset interactively:
```bash
python generate_dataset.py
```

For generating a dataset from preset parameters:
```bash
python generate_dataset.py test
```

For generating a dataset from parameters from a file:
```bash
python generate_dataset.py -p [PARAMETER_FILE.json]
```
